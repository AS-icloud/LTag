The paper-guide trick, confirmed by real test prints (20 Aug 2026): the P831's guides/sensor only recognise A4/A5/B5/Letter. To print something smaller, declare the page as one of those (drives the scale — see the A5 note above — so it still comes out true-to-size), then feed a smaller real sheet.

Turn this on and enter your actual sheet's width across the guide and length along the feed direction — a shaded box in Print Preview shows exactly where it sits on the declared page: centered on the width (your P831 needs paper spanning both sensors, which only happens roughly centered — an off-to-one-side sheet as narrow as ~102mm didn't trigger them, but a full-width 148mm sheet did) and flush to the top (feeding starts there). Use the corner/exact options above to land the tag inside that shaded box — Preview will flag it red if it falls outside the actual paper.

For a narrow continuous roll (e.g. 62mm labels) that's too narrow to trigger the sensor at all: the preview/print math still works the same way — set the physical width to your roll's width — but you'll still need the roll to physically span the sensors to feed at all. Rather than holding two sheets and needing a second person, try taping or clipping the roll segment onto a full A5 "carrier sheet" (or a sheet with a window cut for the label) so it feeds through as one piece — a common trick for running narrow media through printers that expect standard paper. Update (19 Aug 2026, from real ruler-measured test prints): Phomemo's app doesn't scale to a fixed area — it does a plain "fit whole page to the loaded physical paper" (like a normal print dialog's Fit-to-Page), centering the result. Four calibration prints (86×46 and 46×86, from both the iPhone and Mac copies of the app) all landed within a couple mm of exactly 148 × 210mm — i.e. real A5 — regardless of what size the PDF page itself declared. So the page's declared size barely matters at all; only its aspect ratio does, since that's what "fit" scales by.

The fix: use the "Use real A5 page" button below instead of this checkbox. It sets the PDF page to the exact physical A5 size, so Phomemo's fit-to-page has nothing left to rescale (scale ≈ 1) and your margins print as typed. This area-based auto-margin is kept only as a fallback for other printers/apps that might genuinely scale by area — leave it off for Phomemo.
"Real / actual size" builds a custom page sized exactly to your design plus these margins — no wasted paper, and no fixed A6/A5/A4 choice to worry about (handy for label printers or die-cut sheets). "Virtual paper" places the design on a standard page size instead, useful for printing on ordinary printer paper and cutting it out. Position on page only applies to Virtual paper — Real/actual size always fits the page exactly to the design, so there's no extra room to position within.
